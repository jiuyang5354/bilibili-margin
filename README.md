# 映间 MARGIN 0.6

重新设计 B 站首页与视频播放页的 Chrome / Edge 扩展（MV3），基于 BewlyBewly。

## 安装

1. 下载本仓库（Code → Download ZIP）或直接下载 `margin-v6-extension.zip`，解压到一个文件夹。
2. 打开 `chrome://extensions/` 或 `edge://extensions/`，开启「开发者模式」。
3. 点「加载已解压的扩展程序」，选择**直接包含 `manifest.json` 的那一层文件夹**（`margin-v6-extension.zip` 解压后即是这一层；仓库根目录也是）。
4. 停用其他 B 站首页/播放页重设计扩展后再查看本版。

## 使用

- 访问 B 站首页或 `/video/BV…` 播放页。首页视频默认在新标签页打开原生播放页。
- 播放页使用黑白灰外观，保留 B 站原生播放器、弹幕、清晰度、倍速、全屏、账号操作和评论。播放页顶部可切换深浅色。
- 在原链接后加 `?margin=off` 可查看未修改的页面。
- 弹窗：总开关即时生效；「重构作用域」可只改首页或只改播放页，即时生效；「视觉风格」切换深浅色，刷新页面后生效（「跟随系统」按切换时的系统外观取值）。

## 说明

本仓库只包含编译后的扩展文件，`content/index.js` 与 `background/index.js` 为构建产物，未附带源码与构建脚本。

范围：B 站普通视频页与首页。番剧、直播、稍后再看播放器不在本版播放页的匹配范围。登录、会员内容、广告和媒体可用性仍由 B 站决定。
