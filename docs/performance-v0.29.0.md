## 改动
1. **拦下被藏起来的原版页面脚本**（`src/content/native-guard.ts`）。首页、动态首页、历史、消息这些接管页，原版 B 站页面虽然 `display:none`，整套脚本照跑（7700+ 节点、推荐轮询、埋点、iframe）。document_start 的 MutationObserver 在脚本执行前改 type 并移除，同时移除 modulepreload 和 iframe。
   - 空间页不拦：投稿接口依赖原版脚本写的指纹 cookie，不拦会 412。
   - 任何接口返回 412 / -352 时自动关闭拦截（`margin:native-guard=0`），下次进页面放行原版补 cookie，成功接管后再打开。
   - 设置里关掉映间：关闭拦截并刷新一次回到完整原版。
2. **天气点阵天空**不再每 166ms 重写 `innerHTML`，每层一个固定 `<path>` 只改变了的 `d`。
3. **工牌**链子和卡片停稳 20 帧后停掉 rAF，指针移动 / 拖动 / 翻面 / 窗口缩放时唤醒（以前打开期间一直 60fps）。
