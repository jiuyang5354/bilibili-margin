映间 MARGIN 隐私政策

最后更新于 2026-11-22（0.6.92）

映间 MARGIN（以下简称「本扩展」）是一个开源的浏览器扩展，用于重新设计 bilibili.com 的页面外观并提供可选的浏览辅助功能。

我们收集什么

本扩展没有开发者运营的数据服务器，不做使用行为统计或广告分析。设置、足迹和自定义背景保存在本机；天气与可选的社区广告跳过功能会向下面列出的第三方服务发送必要的网络请求。

本扩展的「允许外部辅助服务」默认关闭。天气定位与查询、社区广告片段、GitHub 更新查询均受此开关限制。B 站原有功能、视频 CDN、账号操作与页面统计不受此开关控制。

自定义背景支持用户主动填写 HTTPS 图片直链。点击预览时会请求该图片服务，应用后浏览器会继续从该地址加载背景；图片服务会接收请求 IP 及浏览器按自身策略发送的请求信息。链接保存在本机的背景图片存储中，设置导出排除该内容。这类图片请求由用户明确预览、应用触发，独立于「允许外部辅助服务」开关。

聆听模式由你点击播放页耳机按钮开启。频谱在本机分析当前视频的音轨，导入的歌词及已加载字幕只在当前页面内存中处理。封面和作者信息通过现有 B 站视频信息接口及页面封面来源读取。退出聆听模式时释放音轨分析资源，关闭页面后释放歌词内容。

本地存储

以下内容保存在你自己浏览器的 chrome.storage 中： - 扩展设置（开关、主题、背景、过滤词、屏蔽的 UP 主等） - 「B站足迹」热力图使用的每天首次打开时间和停留时长（按日期统计；由扩展的后台 service worker 在本机累计） - 你选择的自定义背景图片 - 打开实验功能「X 式重排」后：从你的 B 站观看历史算出的 UP 偏好分和看过的视频 ID（6 小时更新一次），以及你点「不感兴趣」/ 屏蔽的 UP 主计数 - 主动打开「保存最近搜索」后，最近 8 条搜索词及时间；30 天后过期，下次读取时清理。默认不记录，不读取或迁移旧版本保存在网页中的搜索记录。 - 开启「更新提醒」后，发现的新版本号与官方发布页地址；提醒看过后即不再重复提示，卸载扩展一并清除。

App 推荐流授权默认保存在后台可访问的 chrome.storage.session 中，关闭浏览器会话后清除。用户主动开启「记住授权」后，凭证与 UID 保存在扩展来源的专用 IndexedDB 中，最多 30 天，并以 B 站授权有效期为上限。关闭该选项会删除持久记录，并将当前授权保留到本次会话结束。取消授权、接口报告授权失效或读取到过期记录时，会清理对应凭据。凭据不会写入设置导出或日志。取消本机授权后，B 站服务端签发令牌的状态仍由 B 站管理。

卸载扩展会删除扩展存储中的这些内容。设置面板里的「导出」会把设置和足迹保存成你电脑上的一个 JSON 文件，只在你点击时生成，不会上传；已导出的文件需要你自行删除。

天气城市、坐标、位置来源和更新时间保存在扩展的 chrome.storage.local 中，在不同 B 站子域间共用。升级时迁移旧版本在当前网页保存的明确手动城市；旧自动位置会重新查询。自动 IP 粗定位成功后缓存 6 小时，失败不保存虚构位置；手动城市由你主动修改。中文城市索引随扩展提供，本地匹配不发送搜索内容。

天气预报缓存仍保存在 B 站页面的 localStorage 中，30 分钟内可复用。清除 B 站网站数据会删除预报缓存；卸载扩展不会自动清除网站的 localStorage。本次没有新增设备定位权限，也不读取 GPS 或持续追踪位置。

网络请求

  • 开启「弹幕跳转建议」时（默认关闭），向 B 站读取当前 BV 视频的分 P 元数据和弹幕。发送者哈希仅在当前页面内存中用于去重，候选时间在本机计算，用户点击后跳转。关闭时取消请求并清除提示。

  • 私信图片在本机预览，只有点击「发送」后才上传到 B 站图床，并通过 B 站私信接口发送给选定联系人；不会上传到开发者服务器或 21st。打开表情面板时向 B 站请求当前账号可用的表情包，表情图片来自 B 站图床。

  • 本扩展在 bilibili.com 页面内，以你已登录的身份调用 B 站自己的公开接口（推荐、热门、搜索、收藏夹、稍后再看、历史记录），数据只用于在页面上显示，不会发送给任何第三方。

  • 手动安装版本仅在允许外部辅助服务后，打开弹窗时才访问 api.github.com 查询更新。开启「更新提醒」后（默认关闭），后台会按你设定的周期访问同一接口，查询结果只保存在本机。不附带 B 站 Cookie、账号或搜索内容；GitHub 仍会接收请求 IP 和常规请求信息。从商店安装的版本不发送这个请求。

  • 天气首次获取且没有已保存城市时，会请求 ipwho.is，由该服务根据请求来源 IP 估算城市及经纬度；不使用浏览器的精确位置权限。网络服务会接收到你的 IP 地址和常规请求信息。

  • 国内城市优先通过中央气象台的 www.nmc.cn 查询省份、城市站点和公开天气实况／日预报，仅发送省份代码或所选城市的站点代码，不附带经纬度、B 站账号、Cookie 或页面来源；不下载和执行该网站的脚本。中央气象台数据缺失时不会伪造逐小时预报或降水概率，天气卡注明数据来源与实况发布时间。

  • 国内来源无法匹配、暂不可用或查询海外城市时，沿用 api.open-meteo.com，发送当前城市的经纬度；手动搜索城市时，会向 geocoding-api.open-meteo.com 发送你输入的城市名称。这些请求不附带 B 站账号、收藏或观看历史。第三方服务的数据处理规则请参阅 ipwho.is 隐私政策 和 Open-Meteo 隐私政策。

  • 打开实验功能「App 推荐流」时（默认关闭），扩展后台会请求 app.bilibili.com 获取首页推荐、提交「不感兴趣」；扫码授权时页面会请求 passport.bilibili.com 的 TV 扫码登录接口。这些请求只发给 B 站。

  • 开启「跳过视频内广告」时（默认关闭），扩展会读取当前 BV 视频的 B 站分 P 元数据，并向 小电视空降助手 的 bsbsb.top 发送 BVID 的 SHA-256 前四位，查询社区标记的广告片段。查询不附带 B 站 Cookie、UID、完整 BVID、页面来源或私人用户 ID；第三方仍能收到网络请求的 IP、浏览器信息与扩展版本。哈希前缀降低查询精度，不代表匿名。查询结果只在后台内存中缓存最多 10 分钟、32 个视频，不写入持久观看记录；关闭功能后不发起新查询，也不再跳过。只读片段，不向服务发送观看统计、投票或片段提交；不通过后台补播改变 B 站完播率。服务协议见接口文档。

权限说明

  • storage：保存上面列出的设置。
  • alarms：更新提醒按设定周期唤醒后台查询版本号；提醒关闭时不创建定时任务。
  • 内容脚本只运行在 *.bilibili.com 页面。
  • app.bilibili.com 主机权限：实验功能「App 推荐流」需要从后台请求 B 站 App 推荐接口（该接口不允许网页跨域访问）；功能关闭时不发请求。
  • bsbsb.top 主机权限：可选的社区广告跳过需要后台读取公开片段；功能关闭时不发起请求。

保护范围与测试

本次增加了请求域名与路径限制、可选请求不带凭据和来源、后台消息来源校验、会话授权隔离，以及搜索高亮的 DOMPurify 过滤。关闭本地搜索记录不会阻止正常搜索与联想词向 B 站发送查询。

天气缓存仍使用原有的 B 站网页 localStorage；只有主动允许外部服务后才会查询天气。本扩展不会清除旧版本写在网页中的数据。足迹计时仍按原版保存在本机，关闭足迹显示并不停止计时。

自动测试使用独立浏览器配置与模拟数据，不读取你的真实账号、私信或授权。扫描结果仅代表已执行检查的覆盖范围，不能证明不存在全部隐私或安全问题。
